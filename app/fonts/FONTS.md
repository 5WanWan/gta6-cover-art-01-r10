# Fonts

The app's lettering uses three fonts, all files under this directory,
all licensed under the SIL Open Font License, Version 1.1 (see OFL.txt):

- `Bangers-Regular.ttf` — the giant comic title ("SUNSET HEIST").
  Copyright 2010 The Bangers Project Authors (https://github.com/googlefonts/bangers).
- `Pacifico-Regular.ttf` — the neon script subtitle ("Vice City nights").
  Copyright 2018 The Pacifico Project Authors (https://github.com/googlefonts/Pacifico).
- `Anton-Regular.ttf` — tagline, starburst stamp, strip and small print.
  Copyright 2020 The Anton Project Authors (https://github.com/googlefonts/AntonFont).

No font is taken from any game, and no font is loaded from the network:
the page's `@font-face` rules point at these local files only.
